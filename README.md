# 秋招工作台 · 单文件版

一个自包含的校招投递管理工作台：**投递看板 + 招聘日程表，全部在一个 HTML 文件里**。
零依赖、零服务器，双击 `index.html` 即可在浏览器中使用。

## 在线使用

**在线版直达：https://realdalao.github.io/qiuzhao-workbench/**

打开即可直接使用（数据保存在你自己的浏览器里，不会上传到任何地方）。

也可以把 `index.html` 下载到本地，双击打开使用，Mac / Windows 均可。

## 功能

- **待投递看板**：一家公司一张卡，可放多个岗位；带截止日期的卡自动按截止排序；岗位点「已投递 / 放弃 / 暂缓」立即落账——点已投递会自动生成一条已投记录，整卡岗位处置完自动关卡并记入已排除清单。
- **全部已投**：按投递日期倒序，状态（投递中 / 笔试 / 面试 / 未通过）可直接在表格里改。
- **待投线索 / 面试中 / 笔试中 / 冲刺项**：线索分组管理，在途的笔试、面试与待拍板的冲刺项各有专区。
- **备选 · 待核实 / 已排除**：留档待核实的公司与已定案排除的原因。
- **日程表**：只留在途事项，分线上测评、线上笔试、线下笔试、AI 测评、真人面试等类型；带日期的笔试/面试自动进入「迫在眉睫」倒计时（只收 7 天内，按今天/明天、2–3 天、4–7 天三档配色）；日程表顶部可按类型筛选；支持导出 `.ics` 导入手机日历。
- **新增/编辑表单**：公司卡、日程、已投记录都可在页面内直接添加和修改。
- **主题**：日间 / 夜间 / 跟随系统三态切换。
- **搜索**：按公司、岗位、城市、状态全文过滤。
- **备份提醒**：数据有改动且满 7 天未导出备份时，页面顶部横幅提醒导出。

## 数据与隐私

- 所有数据保存在**你当前浏览器的 localStorage** 里，不联网、不上传。
- 换浏览器、清缓存会丢失数据，请定期点页面右上角「**导出**」备份（得到一个 JSON 文件），需要时用「**导入**」恢复。
- 把这个文件发给别人时，对方打开是空的（只有示例数据），你的数据不会跟着文件走。

## 让 AI 助手帮你维护

本文件的设计目标之一就是**可由 AI 助手直接维护**：

- 文件顶部有一段写给 AI 的说明（HTML 注释），包含完整的数据结构与落账规则，任何 AI 读文件时先读它即可上手。
- 全部数据以 JSON 形式内嵌在文件的数据块（`id="qz-seed"`）中；页面打开时会比较内嵌数据与浏览器本地数据的 `savedAt`，使用较新的一份。
- 维护方式二选一：① 在页面点「导出数据」把 JSON 交给 AI 改，改完「导入数据」；② 让有文件访问能力的 AI 直接修改本文件的数据块并更新 `savedAt`，重新打开即生效。

## 技术说明

- 单文件：HTML + CSS + 原生 JavaScript，无构建、无第三方库、无网络请求。
- 数据模型：cards（待投卡）/ records（已投记录）/ pauses（暂缓）/ verify（备选）/ excluded（已排除）/ schedule（日程）/ leads（线索）/ interview（面试中）/ test（笔试中）/ rush（冲刺项），详见文件顶部注释。
